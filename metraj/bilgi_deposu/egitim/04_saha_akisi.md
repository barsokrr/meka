# Modül 4 — Saha Akışı (Demir → Kalıp → Beton)

## 1. Tipik kat döngüsü

```
1. Demir montajı     (demir ekibi)
2. Kalıp kurulumu    (siz)
3. Ön kontrol        (mühendis / formen)
4. Beton dökümü      (beton ekibi + pompa)
5. Vibrasyon         (beton ekibi)
6. Kür               (sulama / örtü)
7. Kalıp sökümü      (siz)
8. Temizlik / stok   (siz)
```

## 2. Kalıp öncesi kontrol listesi

- [ ] Donatı projeye uygun (çap, adet, etriye aralığı)
- [ ] Örtü mesafesi sağlanmış (spacer/paspayı)
- [ ] Bindirme boyları yeterli
- [ ] Temizlik (pas, yağ, kırıntı)
- [ ] Kalıp malzemesi sahada
- [ ] İskele / platform hazır (müteahhit)

## 3. Kalıp kurulum adımları

1. **Kot ve eksen** — total station / şerit metre
2. **Alt kalıp / döşeme** — iskele üzerine
3. **Kolon-perde** — düşey kalıp
4. **Kiriş yanları** — döşeme ile birleşim
5. **Boşluklar** — kasa, menfez
6. **Yağlama**
7. **Son kontrol** — hizalama, sızdırmazlık

## 4. Beton dökümünde kalıp ekibi

- Döküm sırasında **devriyede** kal (basınç, sızıntı)
- Vibratör demire değmemeli (örtü bozulması)
- Ani yük (malzeme yığını) kalıba bindirilmemeli

## 5. Söküm

| Eleman | Kabaca bekleme |
|---|---|
| Döşeme alt | 7–14 gün (hava + beton sınıfı) |
| Kolon / perde | 24–48 saat (projeye göre) |
| Kiriş alt | Döşeme ile birlikte |

Erken söküm → çatlak, göçme, ölçü bozukluğu.

## 6. Gecikme nedenleri (süre planı)

- Demir gecikmesi
- Beton / pompa bekleme
- Yağmur
- Vinç yokluğu
- Malzeme gecikmesi

**Plan:** Saf iş ~3 ay · Gerçekçi ~4 ay (12 kişilik ekip, 9.400 m² düz)

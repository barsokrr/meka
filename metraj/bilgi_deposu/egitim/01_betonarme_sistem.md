# Modül 1 — Betonarme Sistem

## 1. Betonarme nedir?

**Beton** basınçta güçlü, **çelik (donatı)** çekmede güçlüdür. İkisi birlikte kullanıldığında **betonarme** eleman oluşur.

```
        ┌─────────────────┐
        │   KALIP (geçici) │
        │  ┌─────────────┐ │
        │  │  DONATI     │ │
        │  │  (çelik)    │ │
        │  └─────────────┘ │
        │     BETON döküm   │
        └─────────────────┘
              ↓ söküm
           Yapı elemanı
```

## 2. Ana yapı elemanları

| Eleman | Görev | Tipik kalıp |
|---|---|---|
| **Radye / temel** | Yükü zemine aktarır | Yan kalıp, radye kalıbı |
| **Perde** | Yatay yük (deprem/rüzgâr) taşır | Çift yüz kalıp |
| **Kolon** | Düşey yük taşır | Dört yüz kalıp |
| **Kiriş** | Döşeme yükünü kolon/perdeye aktarır | Yan + alt kalıp |
| **Döşeme** | Kat tabanı, yatay plak | Alt kalıp + (kenar kalıbı) |

## 3. Kat döngüsü (okul tipi B+Z+3)

1. Temel / bodrum perde-kolon
2. Zemin kat döşeme → kiriş → kolon → perde
3. Üst katlar aynı döngü
4. Çatı döşemesi
5. Kalıp söküm + tekrar kullanım

## 4. Statik sistem (basit)

- **Perde-kolon** düşey taşıyıcı
- **Döşeme-kiriş** yatay taşıyıcı
- Donatı projede **pafta + detay** ile gelir; saha uygulaması demir ekibine ait
- Kalıp ekibi: **donatı yerleşimine uygun** boşluk bırakır, çakışma kontrolü yapar

## 5. Kontrol noktaları

- Kot doğru mu? (±0,00, bodrum, üst katlar)
- Açıklık ve boşluklar (merdiven, asansör, pencere) projeyle uyumlu mu?
- Donatı örtüsü kalıp kurulmadan önce demir ekibi tarafından sağlanmış mı?

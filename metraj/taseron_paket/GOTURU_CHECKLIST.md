# Müteahhite Götürülecek Paket — Checklist

Görüşmeye gitmeden önce hazırla, telefonda **`/kalip/goturu.html`** açık olsun.

## Götür (fiziksel / dijital)

- [ ] **Teklif mektubu** — `Is_Teklif_Mektubu.md` (imzalı PDF veya çıktı)
- [ ] **Fiyat tablosu** — `Isveren_Fiyat_Teklifi_Kalip_Taseronlugu.xlsx`
- [ ] **Metraj cetveli** — `Karsiyaka_Ortaokulu_Kalip_KIRIK_OLCU.xlsx`

- [ ] **Sözleşme taslağı** — `sozlesme_taslagi.md` (PDF)

## Söyle (30 saniye pitch)

> "Karşıyaka kalıp işçiliğini plan metrajına göre **11.773 m²** kırık ölçü ile teklif ediyorum. **500 TL/m²** işçilik, malzeme sizde. **6 kişilik ekip**, **7,5 ay** taahhüt. SGK **Aracı No** modeli, tevkifatlı fatura — yasal, hazırız."

## Görüşmede sorulacaklar (sen sor)

3. Hakediş periyodu (aylık / 45 gün)?

5. Teminat / avans var mı?
